# XDtox — Claude Config

> Inherits global values from ~/.claude/CLAUDE.md

A Figma plugin that strips Adobe XD SVG import artifacts (wrapper groups, clip
masks, background vector paths) from frames in one click.

---

## Project Context

**Stack:** Figma Plugin API (vanilla JS, no framework)
**Build:** esbuild (bundle backend) + Tailwind CSS (utilities), inlined into a
single `dist/ui.html` for Figma's CSP
**Package manager:** npm
**Primary language:** JavaScript (ES2017 target)
**Testing:** Jest (pure helpers only — no Figma/DOM required)

---

## Project Structure

```
src/
  code.js          Plugin backend — runs in the Figma sandbox. Handles
                   scan / strip / resize messages from the UI.
  ui.js            UI logic: event listeners, message passing, DOM updates.
  ui.html          UI markup. Edit THIS, not dist/ui.html. Contains
                   /* INLINE_FONTS */, /* INLINE_CSS */, /* INLINE_JS */
                   placeholders that build.js fills.
  helpers.js       Pure, testable detection functions. Bundled into code.js
                   by esbuild — no manual sync needed.
  helpers.test.js  Jest unit tests for every helper.
  styles.css       Tailwind source + @layer components/utilities for custom
                   CSS (clip-paths, animations, scrollbars).
scripts/
  build.js         Bundle + inline + cache-buster pipeline.
  fonts/           Base64 woff2 @font-face generation (self-contained fonts).
  get-cache-buster.js
demo/
  dev.js, server.js, index.html, mock-data.js
                   Local preview harness with a mock Figma API.
dist/              Build output Figma loads. Generated — do not hand-edit.
manifest.json      Figma plugin manifest.
```

---

## Code Reuse

- Detection/parsing logic goes in `src/helpers.js` as **pure functions**, then
  gets a test in `src/helpers.test.js`. This is the only unit-tested layer.
- Check existing helpers before adding new detection logic.
- Extract logic used in 2+ places into a helper; inline until it recurs.
- Backend (`code.js`) and UI (`ui.js`) communicate only via `postMessage`
  (`scan`, `strip`, `resize`) — keep that message contract in sync on both sides.

---

## Stack Conventions

- **Styling:** Tailwind utility classes directly in `src/ui.html`. Custom CSS
  that can't be a utility → `@layer components`/`@layer utilities` in
  `src/styles.css`. Fonts: Space Mono (mono), Syne (display).
- **No network access** — manifest declares `allowedDomains: ["none"]`. Never
  add external requests, CDN scripts, or remote assets; everything is inlined.
- **Position preservation** — node reparenting must keep original x/y. This is a
  core guarantee; don't regress it.
- Build target is ES2017; avoid syntax esbuild would need to down-level further.

## Off Limits

- **Don't hand-edit `dist/`** — it's generated by `npm run build`. Edit `src/`.
- **Don't edit `scripts/fonts/fonts.inline.css` by hand** — regenerate via
  `scripts/fonts/build-fonts.js`.
- Don't remove the `/* INLINE_* */` placeholders in `src/ui.html` — build.js
  errors out without them.

## Commands to Know

```bash
npm run dev       ← Local UI preview at localhost:3000 (live CSS + mock Figma API)
npm test          ← Jest on src/helpers.test.js — run before committing
npm run lint      ← ESLint (flat config). Must be error-free before committing.
npm run lint:fix  ← ESLint with autofix
npm run format    ← Prettier --write across the repo
npm run build     ← Bundle code.js, compile CSS, inline into dist/ui.html
npm run demo      ← Build then serve the demo
```

**Linting:** ESLint 9 flat config (`eslint.config.js`) with per-area env
overrides (Figma sandbox / browser / Jest / Node). Prettier handles formatting
(`.prettierrc.json`). `dist/`, `*.html`, and generated font CSS are ignored.
UI functions called from inline `on*` handlers in `ui.html` are legitimately
"unused" to ESLint, so `no-unused-vars`/`no-redeclare` are warnings in `ui.js`.

After `npm run build`, reload in Figma: **Plugins → Development → XDtox → Reload plugin**.

## Notes

- The strip operation is **not undoable via the plugin** — users rely on Figma's
  native Cmd/Ctrl+Z. Preserve this expectation; don't add irreversible steps
  without a warning.
- Existing files predate Prettier and use column-aligned style (e.g.
  `scripts/build.js`). Don't blanket-run `npm run format` on them in unrelated
  changes — it produces large noisy diffs. Format files you're already editing.
