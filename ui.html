UnXDfy
Adobe XD import artifact stripper
Status
—
v1.0 · unxdfy
What this does
When SVGs exported from Adobe XD are imported into Figma, each frame gets wrapped in redundant groups, a clip mask node is added, and the frame background becomes a vector path instead of a proper fill. UnXDfy fixes all three.
The XD wrapper structure
⬜ Frame "Menu-Dash – 7"
  ⬜ Group "Clip path group" ← removed
    ⬜ Group "Menu-Dash – 7" ← ungrouped
      ⬛ Vector (background fill) ← promoted
      ↳ your actual content
    ⊗ clip-Menu-Dash_7 ← deleted
What gets fixed
1
Wrapper groups removed — the outer "Clip path group" and inner frame-name group are both ungrouped, placing content directly inside the Figma frame.
2
Clip mask deleted — the clip-{name} node XD adds as a clipping mask is removed entirely.
3
Background fill promoted — if a full-frame vector path is found at the bottom of the layer stack, its fill colour is moved to the frame's fill property and the vector is deleted.
How to use
A
Select frames in Figma to target only those, or select nothing to scan by page or whole file using the toggle.
B
Scan to detect affected frames and review the list before making any changes.
C
Strip to apply all fixes. Positions are preserved throughout.
