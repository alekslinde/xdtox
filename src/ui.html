What this does

When SVGs exported from Adobe XD are imported into Figma, each frame gets wrapped in redundant groups, a clip mask node is added, and the frame background becomes a vector path instead of a proper fill. XDtox fixes all three.

The XD wrapper structure
Frame "Frame name"
  Group "Clip path group"
    Group "Frame name" ← unwrapped
      Vector (bg fill) ← promoted
      ↳ your content
    clip-Frame-name ← deleted
What gets fixed
1.

Wrapper groups removed — outer "Clip path group" and inner frame-name group unwrapped; content placed directly in the frame.

2.

Clip mask deleted — the clip-{name} node is removed entirely.

3.

Background fill promoted — full-frame vector path at bottom of stack is converted to the frame's fill and deleted.

How to use
A. Choose This page or Whole file, then click Find.
B. Review the detected frames. Use the locate button on each row to identify them on the canvas.
C. Click Strip frames to clean them all.
